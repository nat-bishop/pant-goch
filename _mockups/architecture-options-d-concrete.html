The LLM stops reading player input and starts writing structured opportunities. Canon & verdict are no longer inferred — they're authored as effects on chosen options. The engine becomes simpler, not more complex.

02

The shift loop, universal.

One pattern, regardless of story. A shift opens; the tableau-gen LLM proposes a hand of opportunities; the player allocates tokens; chosen opportunities resolve as mini-scenes with 2–3 authored choice nodes; effects fire; the shift ends; state advances.

Engine · deterministic, owns all state
LLM · constrained generators, prose only
Player · selection input, no typing

04

What the LLM is allowed to generate.

Two narrow jobs, both schema-constrained. The LLM never invents structure — it picks from authored templates and fills authored slots. Every output flows through validation before reaching the player.

Agent · LLM job 1
tableau-gen
Each shift opens. Engine passes state + eligible_templates. LLM picks N templates and writes flavor text. Never invents a new template.
Input
{
  "shift_index": 14,
  "waypoint": "holloway_annex",
  "qualities": { candor: 0.54, trust: 0.39, ... },
  "recent_choices": ["answered_directly", ...],
  "eligible_templates": [
    "elder_summons",        # predicate-gated
    "office_dispatch",
    "well_observer",
    "file_report",
    ...
  ],
  "slots": 4
}
Output
[
  {
    "template_id": "elder_summons",        # must be in eligible_templates
    "flavor": "She has a question she won't
              write down.",                 # ≤120 chars
    "cost": 1
  },
  { "template_id": "office_dispatch", ... },
  { "template_id": "well_observer", ... },
  { "template_id": "file_report", ... }
]
Validation (engine-side)
# Rejected if any output:
#   - template_id not in eligible_templates
#   - flavor exceeds max length / contains state writes
#   - duplicate templates
#   - cost differs from template definition
# On rejection: retry once, then fall back to authored defaults
Agent · LLM job 2
scene-render
Fires when player commits a token. Engine passes the authored beat + state. LLM renders prose. Choices, effects, and node graph are authored, not generated.
Input
{
  "beat_id": "elder_summons",
  "scene_node": "opening",
  "node_template": {
    "prose_seed": "Elder receives player in
                    smaller room. Tea steeped
                    too long...",
    "npc_lines": [
      "They sent another like you
       eleven years ago..."
    ],
    "tone": "watchful, faintly hostile",
    "choices": [...]              # authored, passed for context
  },
  "player_canon": { name: "Marcus", ... },
  "recent_arc": [...]
}
Output
{
  "prose": "She receives you in the smaller of
            the two rooms. There is a chair for
            you that is older than the chair
            for her, which seems deliberate..."
  # That's it. No choices, no effects, no canon.
}
Validation (engine-side)
# Rejected if any output:
#   - exceeds max length
#   - contradicts must_include / must_not facts
#   - missing required tone / register markers
#   - attempts choice generation (sanitized away)
# Choices come from the authored beat, NOT the LLM.
05

How this avoids the AI Dungeon trap.

AI Dungeon's failure mode is the LLM authoring world structure. Here, the LLM only fills holes the engine punches. Five checkpoints, each enforced by a specific piece of the architecture.

i
The LLM fills slots in an authored schema, never authors free-form.
Tableau-gen output validated against eligible_templates; scene-render output is prose only — choices come from the authored beat. LLM cannot introduce new templates, new choices, or new effects.
ii
All state writes are authored and gated through one function.
apply_literal_effects remains the only mutation path. Choice metadata carries the effect; LLM output never reaches state. Drift suite already validates this; selection input strengthens it.
iii
The engine owns pacing and arc shape, not the LLM.
Shifts start/end deterministically. Waypoints advance on audit_clock_quality thresholds. Terminals are still authored one-shot beats. The LLM cannot extend a session or skip a beat.
iv
Validation is defense-in-depth, not one prompt.
Schema validation, length limits, must-include facts, retry-once-then-fallback, and the encoder/engine drift suite. Multiple independent guards — same approach as today's fact-checker, scaled across more outputs.
v
Player verbs are constrained — no free text means no improvisation chasing.
Selection & allocation only. The LLM never has to interpret an unbounded player input; it only has to fill flavor slots conditioned on known-vocabulary state. Whole categories of AI-Dungeon-style failure are unreachable.
06

Authoring shape — opportunities + beats with choice nodes.

Two new authoring units. Opportunity templates declare what can surface in a tableau. Beats expand to carry their choice graph (nodes + authored effects). Existing predicates, qualities, and effect ops are untouched.

Opportunity template
scenario.yaml · opportunities[]
- id: elder_summons
  title: "The village elder asked to see you"
  cost: 1
  waypoint: holloway_annex
  surface_when:
    - QualityGte:
        key: local_trust
        v: 0.2
    - Not_:
        BeatFired: elder_summons_scene
  triggers: elder_summons_scene
  flavor_hint: "unanswerable question, written down once"
  # LLM fills 'flavor' at tableau-gen time, conditioned on
  # state. Engine validates against schema + length.
Beat with choice nodes
scenario.yaml · beats[]
- id: elder_summons_scene
  kind: mini_scene
  npc: village_elder
  nodes:
    - id: opening
      prose_seed: "Elder receives player..."
      choices:
        - label: "I file what I see..."
          effects:
            - {key: candor, op: add, v: 0.1}
          next: closing_candor
        - label: "What was wrong with..."
          effects:
            - {key: curiosity, op: add, v: 0.1}
          next: closing_curiosity
        - label: "Wait. Let her finish..."
          effects:
            - {key: patience, op: add, v: 0.1}
          next: closing_patience
    - id: closing_candor
      prose_seed: "She nods once. The tea finally..."
      terminal: true
